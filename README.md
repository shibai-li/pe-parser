# PE 解析器（Windows PE Parser）

> 一个用 C 从零手写的 Windows PE 文件分析工具，不依赖任何第三方库。

在校学习逆向工程的过程中写的第一个工具。用来把 exe 文件的内部结构"打开来看"，
不依赖图形界面工具，全部逻辑自己实现。

---

## 功能

- 识别 **DOS 头**（`MZ` 签名），读取 `e_lfanew`（NT 头的位置）
- 识别 **NT 头**（`PE\0\0` 签名）
- 解析并打印完整的**节表**：节名 / `VirtualSize` / `RVA` / `RawSize` / 文件偏移 / 属性
- 解析并打印完整的**导入表**：依赖了哪些 DLL，每个 DLL 里导入了哪些函数
- 支持 **RVA → 文件偏移** 换算，并显示目标位置的字节
- 自动判断 **PE32 / PE32+**（32 位 / 64 位）
- 文件不是 PE 时给出明确提示，不会崩溃

---

## 编译

需要 gcc（本机用的是 w64devkit）。

```
gcc -O0 -m64 -o pe_parser.exe pe_parser.c
```

Windows 下可以直接双击 `编译运行.bat`（自动编译 + 对两个 exe 跑一遍）。

---

## 用法

```
pe_parser.exe <文件.exe>
```
打印这个 exe 的**节表**和**导入表**。

```
pe_parser.exe <文件.exe> --rva 0xA011
```
把 RVA 换算成**文件偏移**，并显示那个位置的字节。

## 运行示例

对 `hello_key.exe`（自制练习靶子）运行：

```
文件: hello_key.exe
读入 93031 字节

========== 节表 ==========
名字      VirtualSize RVA         RawSize     文件偏移     属性
.text     0x00007E70  0x00001000  0x00008000  0x00000600  0x60000020
.data     0x00000120  0x00009000  0x00000200  0x00008600  0xC0000040
.rdata    0x00000FA8  0x0000A000  0x00001000  0x00008800  0x40000040
.pdata    0x00000498  0x0000B000  0x00000600  0x00009800  0x40000040
...
（共 16 个节）

========== 导入表 ==========
OptionalHeader 类型: PE32+ (64位)
导入表 RVA = 0xE000
导入表在文件偏移 0xA400

--- KERNEL32.dll ---
    EnterCriticalSection
    GetLastError
    MultiByteToWideChar
    VirtualProtect
    VirtualQuery
    ...
--- msvcrt.dll ---
    fgets
    strcmp
    strlen
    malloc
    ...
--- USER32.dll ---
    MessageBoxW
```

换算功能（找"生死门"那条 `jne` 指令）：

```
> pe_parser.exe hello_key.exe --rva 0x16B4

目标 RVA = 0x16B4

=> 文件偏移 = 0xCB4  (3252)

那一处的 4 个字节: 75 2A 48 8D
```

`75 2A` 正是 `jne` 指令的机器码 —— 就是程序里判断"密钥对不对"的地方。
拿到文件偏移 `0xCB4` 后，就能用十六进制编辑器直接改它（把 `75 2A` 改成 `90 90`，
条件跳转变成空操作，程序就被爆破掉了）。

## 用到了哪些知识

**PE 文件结构**
- DOS 头 → NT 头（签名 + FileHeader + OptionalHeader）→ 节表 → 节内容
- `e_lfanew`：文件偏移 `0x3C` 处的 4 字节，指向 NT 头
- `DataDirectory`：可选头里的数据目录数组，导入表是第 `[1]` 项
- 节表每项固定 40 字节，以及各字段的偏移

**导入表结构**（三层指针）
- 描述符数组（每项 20 字节，全零项表示结束）
- 名字表（`OriginalFirstThunk` 指向，每项 8 字节，0 表示结束）
- 名称结构（2 字节 hint + 函数名字符串）
- 序号导入的判定（最高位为 1）

**换算**
- RVA 与文件偏移的区别
- 换算公式：`文件偏移 = 节的文件起点 + (RVA − 节的内存起点)`

**数据表示**
- 小端序：所有整数字段都是低位字节在前
- 字节 / 字 / 双字 / 八字节宽度的区分

**C 语言**
- 文件读写：`fopen` / `fread` / `fclose`
- 指针与数组、自定义函数、命令行参数解析（`strtoul`）
- 全局大缓冲区（栈太小，放不下 4MB 的数组）

**踩过的坑**
- **数组越界**：一开始缓冲区只开了 16KB，读 `%04X`（文件偏移 `0x8811`）时越界，
  程序直接崩（`C0000005` 访问违例）。修正：缓冲区放大到 4MB + 读之前检查边界。

---

## 已知限制

- 只读取文件前 4 MB（缓冲区大小固定）
- 只处理 PE32 / PE32+，不处理 COFF 或其它格式
- 不解析导出表、重定位表、资源表
- 不处理加壳 / 损坏的 PE 文件
